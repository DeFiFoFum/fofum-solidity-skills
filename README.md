# Fofum Skills

Claude Code plugins for DeFi security, smart contract auditing, and Solidity development.

## Plugins

| Plugin | Description | Status |
|--------|-------------|--------|
| [solidity-audit](./plugins/solidity-audit) | Comprehensive Solidity security audit skill | 🚧 Beta |

## Installation

```bash
# Install a specific plugin
claude plugin add defifofum/fofum-skills/solidity-audit

# Or install the entire marketplace
claude plugin add defifofum/fofum-skills
```

## Philosophy

- **100% Markdown** — No executable code, no supply chain risk
- **Battle-Tested Methodologies** — Combines Trail of Bits, Code4rena, Sherlock, Cyfrin, SlowMist
- **Real Exploit Examples** — Learn from actual DeFi hacks
- **Multi-Agent Architecture** — Specialized agents work in parallel for thorough coverage
